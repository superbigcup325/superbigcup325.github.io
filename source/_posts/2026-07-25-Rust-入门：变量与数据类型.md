`variables` 示例覆盖了 Rust 中变量声明和使用的主要方式，下面按照代码出现的顺序逐一说明

## Part 1 变量与可变性

```rust
let number = 42;         // 不可变
let mut value = 36;      // 可变
value = 42;
value += 1;              // 可变变量可正常执行
```

Rust 中变量默认是**不可变**（immutable）的。使用 `let` 声明的变量一旦绑定值就不能再修改：

```rust
let x = 5;
x = 6;  // 编译错误：cannot assign twice to immutable variable
```

如果想让变量可变，需要在变量名前加 `mut` 关键字：

```rust
let mut x = 5;
x = 6;  // 允许
```

这个设计是 Rust 的核心原则之一：默认不可变可以避免意外的数据修改，只在明确需要可变时才设置可变。这既能提升代码安全性，又不会牺牲灵活性

## Part 2 变量遮蔽（Shadowing）

```rust
let message = "   ";
let message = message.len();   // 遮蔽：String -> usize
{
    let message = message * 4;
    println!("{message}");     // 12（内层作用域）
}
println!("{message}");         // 3（外层作用域）
```

第二个 `let message` 用 `usize` 类型的值遮蔽了之前的 `&str` 类型的 `message`。这是 Rust 的**变量遮蔽**（shadowing），具备以下特点：

- 允许改变变量的类型（`&str` → `usize`）
- 允许改变可变性（遮蔽后可以重新决定是否可変）
- 遮蔽仅发生在当前作用域内，离开作用域后原来的变量恢复可见（如上例中大括号内部与外部的 `message` 是两个不同的值）

> 补充：shadowing 与 `mut` 不同：`mut` 允许修改同类型变量的值但不能改变类型；shadowing 创建一个全新的变量，可以改变类型

## Part 3 常量

```rust
const MAX_POINT: u32 = 100_000;
const PI: f64 = 3.14;
```

**常量**（constant）使用 `const` 关键字声明，与不可变变量有以下区别：

| 特性       | `let` 不可变变量           | `const` 常量                   |
| ---------- | -------------------------- | ------------------------------ |
| 类型标注   | 通常可省略（由编译器推断） | **必须**显式标注               |
| 赋值目标   | 可以是任何表达式的结果     | 必须是编译期可确定的常量表达式 |
| 作用域     | 局部（块级作用域）         | 任意作用域均可声明             |
| 运行时存在 | 存在于栈内存中             | 编译时内联到使用位置           |

注意到 `100_000` 中的下划线——这是 Rust 中数字字面量的合法写法，用于提升长数字的可读性，不影响实际值。类似的写法也适用于其他数字类型：

```rust
const COLOR_HEX: u32 = 0xFF_FF_FF;
const MILLION: f64 = 1_000_000.0;
```

## Part 4 数据类型

Rust 是**静态类型**语言，所有变量的类型在编译时都必须明确。当无法从上下文推断类型时，需要显式标注：

```rust
let num: i32 = "42".parse().expect("not a number");
```

`"42".parse()` 可以解析为多种数字类型，编译器无法自动确定，此时必须通过 `: i32` 指定

Rust 的数据类型分为两大类：**标量类型**（scalar）和**复合类型**（compound）

### 4.1 标量类型

标量类型表示单个值。Rust 有四种标量类型：

**整型**

| 长度     | 有符号  | 无符号  |
| -------- | ------- | ------- |
| 8 位     | `i8`    | `u8`    |
| 16 位    | `i16`   | `u16`   |
| 32 位    | `i32`   | `u32`   |
| 64 位    | `i64`   | `u64`   |
| 128 位   | `i128`  | `u128`  |
| 平台相关 | `isize` | `usize` |

其中平台相关部分在操作系统为32位中，被推导为i32,以此类推

默认类型是 `i32`。整型字面值可以用多种方式书写：

```rust
let a = 100;           // 十进制（默认）
let b = 0xFF;          // 十六进制
let c = 0o77;          // 八进制
let d = 0b1010;        // 二进制
let e = b'A';          // 字节字面量（仅 u8）
```

**浮点型**

```rust
let x = 3.14;       // f64（默认，双精度）
let y: f32 = 3.14;  // f32（单精度）
```

默认类型是 `f64`。在现代 CPU 上 `f64` 与 `f32` 速度相近，但精度更高

**布尔型**

```rust
let is_ok: bool = true;
```

**字符型**

```rust
let c: char = '中';
```

`char` 占 4 字节，可以表示任意 Unicode 字符，包括中文、emoji 等

### 4.2 复合类型

复合类型将多个值组合成一个类型。Rust 有两种内建的复合类型：元组和数组

**元组（tuple）**

元组将多个不同类型的值组合在一起，长度固定，声明后不能增加或删除元素：

```rust
let tup: (i32, u8, f64) = (114, 5, 0.14);
```

访问元组元素有两种方式：

```rust
// 方式一：解构（destructuring）
let (x, y, z) = tup;
println!("{}, {}, {}", x, y, z);

// 方式二：索引访问（0-based）
println!("{}, {}, {}", tup.0, tup.1, tup.2);
```

元组可以包含不同类型，也允许只包含一个值——此时需要在类型和值后加逗号以区分于普通括号表达式：

```rust
let single: (i32,) = (42,);
```

**数组（array）**

数组是多个**相同类型**值的集合，长度也在编译时固定：

```rust
let arr: [i32; 5] = [1, 2, 3, 4, 5];
```

类型签名 `[i32; 5]` 中的 `5` 表示长度，是数组类型的一部分。数组也可以简写：

```rust
let zeros = [0; 3];  // 等价于 [0, 0, 0]
```

当需要动态增删元素的集合时，应使用 `Vec`（向量）而非数组，后续章节会介绍

## 小结

| 概念       | 一句话                                                       |
| ---------- | ------------------------------------------------------------ |
| 不可变变量 | `let` 声明，默认不可变，值绑定后不能修改                     |
| 可变变量   | `let mut` 声明，允许修改同一变量的值                         |
| shadowing  | 用 `let` 再次声明同名变量，可改变类型，旧变量被遮蔽          |
| 常量       | `const` 声明，必须标注类型，编译期内联，可在任意作用域使用   |
| 标量类型   | 单个值：整型、浮点型、布尔型、字符型                         |
| 复合类型   | 多个值组合：元组（可异类，长度固定）、数组（同类，长度固定） |
