## Part 1 函数

函数是 Rust 程序的基本组织单元。`fn` 关键字用于声明函数，函数名后跟参数列表和返回类型

### 1.1 命名规范

Rust 使用 **snake_case** 风格命名函数和变量，即所有字母小写，单词间用下划线分隔：

```rust
fn hello_world() {
    println!("hello world");
}

fn print_labled_measurement(value: i32, unit_label: char) {
    println!("the measurement is: {value}{unit_label}");
}
```

### 1.2 参数

所有参数都要显式标明类型：

```rust
fn print_labled_measurement(value: i32, unit_label: char) {
```

每个参数由 `name: type` 组成，多个参数用逗号分隔。调用时传入对应类型的具体值：

```rust
print_labled_measurement(5, 'h');
```

### 1.3 语句与表达式

理解**语句**（statement）和**表达式**（expression）的区别是掌握 Rust 函数的关键：

- **语句**执行操作但不返回值(或者说返回空的tuple,即`()`)，以分号结尾
- **表达式**计算并产生一个值，没有分号

```rust
let result = {
    let x = 1;         // 语句，不返回值
    x + 1              // 表达式，值为 2
};
println!("{result}");  // 2
```

大括号 `{}` 包裹的代码块本身是一个表达式，其值为块中最后一个表达式的结果。`let x = 1` 是语句（不返回值），`x + 1` 是表达式（值为 2），整个块的值赋给了 `result`

> 补充：表达式末尾没有分号。如果在 `x + 1` 后面加个分号，它就变成了语句，代码块的值会变成 `()`（单元类型）

### 1.4 返回值

函数使用 `->` 声明返回类型。函数体最后一个表达式的值就是返回值，无需 `return` 关键字：

```rust
fn plus_five(x: i32) -> i32 {
    x + 5  // 隐式返回，等效于 return x + 5;
}
```

如果函数没有返回值，返回类型可以省略，此时默认返回 `()`（单元类型）

Rust 也支持使用 `return` 关键字进行显式返回，常用于提前退出函数：

```rust
fn early_return(x: i32) -> i32 {
    if x < 0 {
        return 0;  // 提前返回
    }
    x + 5          // 隐式返回
}
```

隐式返回更简洁，是 Rust 中的惯用风格；`return` 更适合需要提前退出的场景



## Part 2 控制流

### 2.1 if 表达式

`if` 是表达式，可以返回值。条件必须是 `bool` 类型，值得注意的是，rust此时不会自动将非布尔值转换为布尔值：

```rust
let number = 7;

if number < 5 {
    println!("小于 5");
} else if number < 10 {
    println!("大于等于 5，小于 10");
} else {
    println!("大于等于 10");
}
```

作为表达式使用时，各分支返回的类型必须一致：

```rust
let result = if number > 5 { "big" } else { "small" };
```

### 2.2 loop 循环

`loop` 会无限重复执行，除非显式 `break`：

```rust
let mut counter = 0;

let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2;  // break 可以返回值
    }
};

println!("{result}"); // 20
```

`break` 后面可以跟一个表达式，作为 `loop` 块的值

### 2.3 循环标签

当存在嵌套循环时，**循环标签**（loop label）可以指定 `break` 或 `continue` 作用于哪一层循环。标签以单引号开头：

```rust
let mut count = 0;
'counting_up: loop {
    println!("count = {count}");
    let mut remaining = 10;

    loop {
        println!("remaining = {remaining}");
        if remaining == 9 {
            break;               // 只 break 内层循环
        }
        if count == 2 {
            break 'counting_up;  // break 外层循环
        }
        remaining -= 1;
    }
    count += 1;
}
println!("count result = {count}");
```

`break 'counting_up` 直接终止外层循环，而内层的 `break` 只退出当前循环

### 2.4 while 循环

`while` 在条件为真时重复执行：

```rust
let mut number = 3;
while number != 0 {
    println!("{number}");
    number -= 1;
}
println!("LIFTOFF!");
```

### 2.5 for 循环与 Range

`for` 是 Rust 中最常用的循环结构，用于遍历迭代器：

```rust
let arr = [10, 20, 30, 40, 50];
for element in arr {
    println!("the value is: {element}");
}
```

配合**范围表达式**（range）可以遍历一个数字区间。`a..b` 表示从 `a` 到 `b`（不含 `b`）的半开区间，`a..=b` 表示包含 `b` 的闭合区间：

```rust
for number in 1..4 {
    println!("{number}");  // 1, 2, 3
}

for number in 1..=4 {
    println!("{number}");  // 1, 2, 3, 4
}
```

`for` 比 `while` 更安全，因为它无需手动管理索引和边界条件，编译器会代为处理

## 小结

| 概念     | 一句话                                         |
| -------- | ---------------------------------------------- |
| 函数声明 | `fn name(params) -> ReturnType { body }`       |
| 参数     | 必须标注类型，格式 `name: type`                |
| 语句     | 执行操作，以分号结尾，不返回值                 |
| 表达式   | 计算值，没有分号，可作为返回值                 |
| 隐式返回 | 函数体最后一个表达式的值自动作为返回值         |
| `if`     | 条件表达式，`bool` 类型，可返回值              |
| `loop`   | 无限循环，`break` 可返回值                     |
| 循环标签 | `'label: loop { break 'label; }`，用于嵌套循环 |
| `while`  | 条件循环，条件为 `false` 时退出                |
| `for`    | 遍历迭代器，配合 range `a..b` 使用             |
