FastAPI 是构建 Web API 的 Python 框架，它有两个鲜明的特点：**完全基于类型提示（Type Hints）工作**，以及**靠 async/await 拿到极高的性能**。所以在正式进入 FastAPI 教程之前，本系列第一篇先把这两个前置知识讲清楚。看完这篇，就能明白 FastAPI 的很多"魔法"其实只是标准 Python 而已

## Part 1 Python 类型提示（Type Hints）

类型提示也叫"类型注解"，是 Python 的一种可选语法，用来声明变量的**类型**（例如 `str`、`int`、`float`、`bool`）。声明了类型之后，编辑器和工具就能给你更好的支持

### 1.1 动机：编辑器支持

先看一个最简单的程序：

```python
def get_full_name(first_name, last_name):
    full_name = first_name.title() + " " + last_name.title()
    return full_name


print(get_full_name("john", "doe"))
```

这个函数把名和姓各自的首字母转大写再拼接，运行输出 `John Doe`。它跑起来没问题，但对编辑器不友好：没声明类型，编辑器就不知道 `first_name` 是什么，补全不出任何方法

现在只改参数这一行，给它们加上类型：

```python
def get_full_name(first_name: str, last_name: str):
    full_name = first_name.title() + " " + last_name.title()
    return full_name


print(get_full_name("john", "doe"))
```

类型提示的作用就在这里：**让编辑器能确定变量是什么类型，从而补全/提示出相应的方法**——现在补全列表里就会出现 `title`、`upper`、`capitalize` 等字符串方法，你只管挑想要的那个

这里有两个关键点：

- 我们用的是冒号 `:`，不是等号 `=`。`first_name: str` 是**类型注解**，跟默认值 `first_name="john"` 是两码事
- 加类型提示**不改变运行行为**——去掉它们，程序照常跑

类型提示还能带来**错误检查**。看这个已经加了类型的函数：

```python
def get_name_with_age(name: str, age: int):
    name_with_age = name + " is this old: " + age
    return name_with_age
```

编辑器知道 `name` 是 `str`、`age` 是 `int`，于是能直接标出这行 `str` 拼 `int` 的错误，并提示你用 `str(age)` 转换：

```python
def get_name_with_age(name: str, age: int):
    name_with_age = name + " is this old: " + str(age)
    return name_with_age
```

### 1.2 常用的类型声明写法

类型提示最常用的**声明位置是函数参数**，这也是后续 FastAPI 里最重要的位置——路径参数、查询参数、请求体全靠它。常见的写法就下面几类，先看总览：

| 场景       | 声明写法                        | 含义                                                      |
| ---------- | ------------------------------- | --------------------------------------------------------- |
| 简单类型   | `item_a: str`                   | 标准类型都能用：`str`、`int`、`float`、`bool`、`bytes` 等 |
| 任意类型   | `data: Any`                     | 可以是任何类型，从 `typing` 导入                          |
| 列表       | `items: list[str]`              | 一个 `list`，里面每个元素都是 `str`                       |
| 元组       | `items_t: tuple[int, int, str]` | 恰好 3 个元素，类型依次是 `int`、`int`、`str`             |
| 集合       | `items_s: set[bytes]`           | 一个 `set`，每个元素是 `bytes`                            |
| 字典       | `prices: dict[str, float]`      | 键是 `str`、值是 `float`                                  |
| 联合类型   | `item: int \| str`              | `int` 或 `str` 中的任意一个                               |
| 可空       | `name: str \| None = None`      | 可能是 `str`，也可能是 `None`                             |
| 类作为类型 | `one_person: Person`            | `Person` 类的**实例**                                     |

下面挑几类重点展开。

`list`、`tuple`、`set`、`dict` 这类能接收"类型参数"的类型叫**泛型类型（Generic types）**，方括号里放的是内部元素/结构的类型，Python 内置类型就能当泛型用：

```python
def process_items(items: list[str]):
    for item in items:
        print(item)


def process_items(items_t: tuple[int, int, str], items_s: set[bytes]):
    return items_t, items_s


def process_items(prices: dict[str, float]):
    for item_name, item_price in prices.items():
        print(item_name)
        print(item_price)
```

`list[str]` 表示"变量 `items` 是一个 `list`，每个元素都是 `str`"，于是编辑器在遍历时也知道 `item` 是 `str`，又能给出补全。`dict` 要传**两个**类型参数，用逗号隔开：第一个是键的类型、第二个是值的类型

声明"可以是若干类型中的任意一个"，用竖线 `|` 把两个类型隔开，叫**联合类型（Union）**。它最常见的一个用法是声明**可空**：

```python
def process_item(item: int | str):
    print(item)


def say_hi(name: str | None = None):
    if name is not None:
        print(f"Hey {name}!")
    else:
        print("Hello World")
```

`str | None` 表示 `name` 可能是 `str`、也可能是 `None`，它能帮编辑器发现"假设值一定是 `str`，实际可能是 `None`"的错误

类也能当类型用，表示"是这个类的**一个实例**"（注意：不表示"是 `Person` 这个类本身"）：

```python
class Person:
    def __init__(self, name: str):
        self.name = name


def get_person_name(one_person: Person):
    return one_person.name
```

声明之后编辑器自然又能给出支持，比如补全出 `.name`

### 1.3 类型提示如何支撑 FastAPI

#### Pydantic：数据校验库

**Pydantic** 是一个做数据校验的 Python 库：你用带属性的类声明数据的"形状"，每个属性都有类型；然后用某些值创建实例，它会**校验**这些值、在需要时把它们**转换**成合适的类型，最后给你一个装好所有数据的对象，并且这个对象还有完整的编辑器支持：

```python
from datetime import datetime

from pydantic import BaseModel


class User(BaseModel):
    id: int
    name: str = "John Doe"
    signup_ts: datetime | None = None
    friends: list[int] = []


external_data = {
    "id": "123",
    "signup_ts": "2017-06-01 12:22",
    "friends": [1, "2", b"3"],
}
user = User(**external_data)
print(user)
# > User id=123 name='John Doe' signup_ts=datetime.datetime(2017, 6, 1, 12, 22) friends=[1, 2, 3]
print(user.id)
# > 123
```

注意：传入的外部数据很"脏"：`id` 是字符串 `"123"`，`signup_ts` 是字符串 `"2017-06-01 12:22"`，`friends` 里混着整数、字符串甚至字节 `b"3"`。Pydantic 实例化时全部处理好了：**字符串数字转成 `int`、字节转成 `int`、字符串时间转成 `datetime`**。**FastAPI 完全基于 Pydantic**——这就是为什么它能用同一份类型声明做校验和转换

#### Annotated：类型之外的附加元数据

Python 还能往类型提示里塞**附加元数据**，用 `typing` 里的 `Annotated`：

```python
from typing import Annotated


def say_hello(name: Annotated[str, "this is just metadata"]) -> str:
    return f"Hello {name}"
```

`Annotated[str, "..."]` 的第一个参数是**真实类型**（这里是 `str`），剩下的都是给其他工具看的元数据。Python 本身对 `Annotated` 什么也不做，编辑器看到类型仍然是 `str`。但你可以借用这块空间，告诉 FastAPI 你希望应用以某种方式表现——后续教程你会看到它有多强大。先记住一点：**它是标准 Python**

#### FastAPI 用类型提示做的事

FastAPI 充分利用这些类型提示：一方面你得到**编辑器支持**和**类型检查**；另一方面，FastAPI 用同一份声明来：

1. **定义需求**：声明路径参数、查询参数、请求头、请求体、依赖等的要求
2. **转换数据**：把请求里的数据转成声明的目标类型
3. **校验数据**：每来一个请求都校验，数据不合法就**自动生成错误响应**返回给客户端
4. **生成 OpenAPI 文档**：用它驱动自动生成的交互式文档界面

听起来有点抽象，没关系，后面教程会一个个看到。关键是：用标准 Python 类型、在**一个地方**做声明，FastAPI 就能替你干一大堆活

## Part 2 并发与 async/await

现代 Python 对**异步代码**有支持：用**协程（coroutines）**加上 **`async` 和 `await`** 语法。这句话拆开看就三块——异步代码、`async`/`await`、协程。下面依次讲

### 2.1 异步代码是什么

异步代码的意思是：语言有办法告诉程序——"代码执行到这里，得等某个**别处的慢东西**完成"。在等待的这段时间里，计算机可以去做别的活，等那个慢东西完成后再回来接着干

"等某个东西"通常指相对慢的 **I/O** 操作（相对 CPU 和内存的速度而言），比如：

- 等待客户端把数据通过网络发过来 / 等待网络把数据送到客户端
- 等待系统读取磁盘上的文件 / 写入磁盘
- 等待远程 API 返回
- 等待数据库操作完成、查询返回结果

因为执行时间主要花在等 I/O 上，这类操作就叫 **I/O bound**（受 I/O 限制）。之所以叫"异步"，是因为程序不必跟慢任务"同步"——不用干等着它完成的那一刻才动手；任务完成后可以稍微排会儿队（几微秒），等程序把手头的活干完再回来取结果。与此相对，"同步"也叫**顺序（sequential）**：程序一步步执行完所有步骤才切换任务，哪怕中间在干等

### 2.2 并发 vs 并行

前面的异步还有个别名，叫**并发（Concurrent）**，它和**并行（Parallel）**不是一回事。两者都涉及"不同的事情差不多同时发生"，但差别很大：

- **并发**：等待时可以**切换去做别的事**——一个处理器在等待的空隙里干别的活。它适合"等待很多"的场景，比如大多数 Web 应用：大量用户、大量网络 I/O。这正是 NodeJS 火起来的原因（虽然它并不并行）
- **并行**：多个处理器**同时干活**，适合计算密集型任务，比如图像/音视频处理、计算机视觉、机器学习这类 **CPU bound**（受 CPU 限制）的工作——就像请 8 个清洁工分区域打扫一栋大房子，比一个人轮着打扫快得多

注意：**并发并不比并行好**，它只是在"等待很多"的场景下更合适，所以通常更适合 Web 开发。而 FastAPI 两种都能用：既有 NodeJS 式的并发，也有 Go 式的并行能力（感谢 Starlette 和底层的 AnyIO）

官方文档用一个汉堡店的故事把两者的差别讲得很生动，有兴趣可以看看：https://fastapi.tiangolo.com/async/#concurrency-and-burgers

### 2.3 async 与 await 语法

现代 Python 定义异步代码的方式很直观，看起来就像普通顺序代码：

```python
burgers = await get_burgers(2)
```

关键是 `await`：它告诉 Python 先等 `get_burgers(2)` 干完它的活，再把结果存进 `burgers`。等待期间 Python 知道它可以去干别的事——比如处理另一个请求

`await` 要生效，必须出现在**支持异步的函数**里，也就是用 `async def` 声明的函数：

```python
async def get_burgers(number: int):
    # 这里做一些异步的事来制作汉堡
    return burgers
```

而不是普通 `def`：

```python
# 这不是异步的
def get_sequential_burgers(number: int):
    # 这里做一些顺序的事来制作汉堡
    return burgers
```

用 `async def` 声明后，Python 就知道函数内部要留意 `await` 表达式，并且可以在合适的时机**暂停**这个函数、去做别的事，再回来继续

反过来，调用 `async def` 函数**必须 await 它**，所以这样写不行：

```python
# 这样不行，因为 get_burgers 是用 async def 定义的
burgers = get_burgers(2)
```

这就引出"鸡生蛋问题"：`async def` 里才能调用 `async def`，那**第一个** async 函数由谁来调？如果你用 FastAPI，完全不用操心——那个"第一个"函数就是你的**路径操作函数**，框架知道该怎么做：

```python
@app.get('/burgers')
async def read_burgers():
    burgers = await get_burgers(2)
    return burgers
```

如果不用 FastAPI 也想写自己的异步代码：Starlette（以及 FastAPI）基于 **AnyIO**，它同时兼容标准库的 `asyncio` 和 Trio；tiangolo 还在 AnyIO 之上写了 **Asyncer**，在需要把异步代码和普通（阻塞/同步）代码混用时特别有用。这部分了解即可

### 2.4 协程（Coroutine）

**协程（Coroutine）**这个高端术语，指的就是 `async def` 函数返回的那个东西。Python 知道它像个函数：可以被启动、会在某刻结束，但内部遇到 `await` 时也可能被**暂停**。它可以类比 Go 的核心特性 **Goroutine**

### 2.5 决策规则（实践总结）

原理清楚了，落到 FastAPI 的路径操作函数上，选 `async def` 还是普通 `def`，记住下面这张表就行：

| 情况                                                             | 用          |
| ---------------------------------------------------------------- | ----------- |
| 第三方库要求 `await` 调用（如 `results = await some_library()`） | `async def` |
| 库不支持 `await`（目前大多数数据库库都这样）                     | 普通 `def`  |
| 应用不需要等待任何外部东西                                       | `async def` |
| 不知道选哪个                                                     | 普通 `def`  |

- 第三方库要求 `await` 时，路径操作函数用 `async def`：

```python
@app.get('/')
async def read_results():
    results = await some_library()
    return results
```

- 第三方库不支持 `await`（比如当前大多数数据库库），就用普通 `def`：

```python
@app.get('/')
def results():
    results = some_library()
    return results
```

`def` 和 `async def` 可以在路径操作函数里**随意混用**，FastAPI 都会正确处理。另外注意：**`await` 只能用在 `async def` 函数里**。只要按上面的规则来，FastAPI 仍然异步工作、速度极快，只是它还能做一些性能优化

### 2.6 技术细节（了解即可）

下面是 FastAPI 底层的实现细节，不感兴趣可以跳过：

- 用普通 `def` 声明的路径操作函数，会被放进**外部线程池**运行、然后被 `await`，而不是直接调用（否则会阻塞服务器）
- **依赖（dependency）**同理：普通 `def` 的依赖跑在线程池里
- 你自己直接调用的**工具函数**：普通 `def` 直接调用即可，`async def` 的则需要 `await`——这两种都不受 FastAPI 影响
- 如果你之前用别的异步框架，习惯给纯计算型路径操作函数用普通 `def` 去省那 ~100 纳秒——在 FastAPI 里效果**正好相反**；除非函数里做了阻塞 I/O，否则用 `async def` 更好

### 2.7 结论

回到开头那句话："现代 Python 用协程支持异步代码，语法是 async/await"——现在应该能看懂了。这套机制（经由 Starlette）就是 FastAPI 高性能的来源

## 小结

| 概念         | 一句话                                                                     |
| ------------ | -------------------------------------------------------------------------- |
| 类型注解     | `参数: 类型`，冒号不是等号，不改变运行行为                                 |
| 泛型         | `list[str]` / `dict[str, float]`，方括号里传内部类型                       |
| Union        | `int \| str`，竖线隔开；`str \| None` 表示可空                             |
| Pydantic     | 用类 + 属性类型声明数据形状，实例化时校验 + 转换，是 FastAPI 的地基        |
| Annotated    | 第一个参数是真实类型，其余是给工具的元数据                                 |
| async def    | 异步函数；`await` 只能在它里面用                                           |
| await        | 等待异步结果，等待期间可以切换去做别的事                                   |
| 并发 vs 并行 | 并发 = 等待时切换任务（Web 适用）；并行 = 多处理器同时干（CPU bound 适用） |
| 协程         | async def 的返回值，可暂停可恢复，类比 Go 的 Goroutine                     |
