`collections` 示例覆盖了 Rust 中最常用的三种集合类型的主要用法，下面按概念逐一说明

## Part 1 Vector

**Vector**（`Vec<T>`）是可变长度的数组，存储**相同类型**的元素序列，所有元素在内存中**连续排列**。它在栈上存放指针、长度和容量三个字段，实际元素在堆上

### 1.1 声明

有两种创建方式：

```rust
let mut v: Vec<i32> = Vec::new();  // 空 Vector，元素类型需推断
v.push(1);

let v2 = vec![1, 2, 3];            // vec! 宏，编译器从元素推断类型
```

`Vec::new()` 创建空 Vector 时无法从元素推断类型，需要类型注解或后续 `push`；`vec!` 宏则直接传入元素，类型一目了然

### 1.2 增删改查

```rust
let mut v = vec![1, 2, 3, 4, 5];

v.push(6);       // 追加到末尾
v.insert(0, 0);  // 指定位置插入
v.pop();         // 弹出末尾元素，返回 Option<T>
v.remove(1);     // 删除指定位置，返回被删除的元素
```

读取元素有两种方式：

```rust
let third = &v[2];   // 索引访问，越界会 panic

match v.get(2) {
    Some(value) => println!("v[2] = {value}"),
    None => println!("out of range"),
}
```

| 方式       | 返回值       | 越界行为    |
| ---------- | ------------ | ----------- |
| `&v[i]`    | `&T`         | panic 崩溃  |
| `v.get(i)` | `Option<&T>` | 返回 `None` |

不确定下标是否会越界时，`get()` 更安全

### 1.3 遍历方式

for 循环是最常用的遍历方式，三种写法对应不同的权限：

```rust
let v = vec![1, 2, 3, 4, 5];

for i in &v {        // 不可变借用
    print!("{i} ");
}

for i in &mut v {    // 可变借用，可修改元素
    *i *= 10;
}

for i in v {         // 获取所有权，v 被移动
    print!("{i} ");
}
```

### 1.4 迭代器与 next

`iter()` 返回迭代器，`next()` 每次取出下一个元素，取完返回 `None`：

```rust
let v = vec![1, 2, 3];
let mut it = v.iter();
assert_eq!(it.next(), Some(&1));
assert_eq!(it.next(), Some(&2));
assert_eq!(it.next(), Some(&3));
assert_eq!(it.next(), None);
```

`next()` 返回 `Option<&T>`，因为迭代器借用元素而不获取所有权。for 循环本质上是迭代器的语法糖——`for i in &v` 会隐式调用 `iter()` 并用 `next()` 逐次取值

## Part 2 String

### 2.1 String 与 &str 的区别

Rust 中有两种字符串类型：

| 类型     | 可变性         | 所有权   | 说明                                         |
| -------- | -------------- | -------- | -------------------------------------------- |
| `String` | 可变，可增删改 | 拥有数据 | 内容在堆上，栈上存指针/长度/容量             |
| `&str`   | 不可变         | 借用     | 字符串切片，通常指向字面值或 String 的一部分 |

字符串字面值 `"hello"` 的类型就是 `&str`

String 内部按 **UTF-8** 编码存储字节，每个字符占用的字节数不固定：英文字符 1 字节，中文字符 3 字节：

```rust
let s = String::from("hello 你好");
println!("{}", s.len());   // 12：5 + 1 + 3 + 3
```

### 2.2 创建

```rust
let s1 = String::from("hello");
let s2 = "hello".to_string();  // 与 String::from 等价
let s3 = String::new();        // 空字符串
```

### 2.3 更新

```rust
let mut s = String::from("foo");
s.push_str("bar");   // 追加字符串切片
s.push('!');         // 追加单个字符
```

`push_str` 接收 `&str`（传入 `&String` 会被 deref coercion 自动转换），`push` 接收单个字符

### 2.4 连接

用 `+` 连接两个 String 时，**第一个参数的所有权会被转移**：

```rust
let s1 = String::from("Hello, ");
let s2 = String::from("world!");
let s3 = s1 + &s2;
// println!("{s1}");  // 编译错误：s1 已被移动
```

`+` 的签名是 `fn add(self, s: &str) -> String`，`s1` 按值传入故所有权被转移，`&s2` 是借用故 `s2` 仍可用

连接多个字符串时更推荐 `format!`，它不夺取任何所有权：

```rust
let a = String::from("tic");
let b = String::from("tac");
let c = String::from("toe");
let game = format!("{a}-{b}-{c}");   // "tic-tac-toe"
// a, b, c 仍然可用
```

### 2.5 为什么 String 不能索引

`String` 不允许通过索引 `s[0]` 访问单个字符，原因有两点：

**1. 索引未必落在字符边界**

UTF-8 是变长编码，`&s[0]` 取到的是第一个**字节**。以 `"你好"` 为例，`&s[0]` 只是"你"的三个字节之一（`0xe4`），并不是一个有效的字符

**2. 无法保证 O(1) 的访问时间复杂度**

其他语言（如 C++ 的 `std::string`）能通过索引 O(1) 访问，是因为索引对齐到了字符。而 Rust 的 String 若想定位第 n 个字符，必须从头逐个检查字节才能找到字符边界，这是 O(n) 的。既然做不到恒定时间复杂度的访问，索引语法就没有意义，反而容易掩盖错误

### 2.6 三种视角

Rust 提供三种视角观察字符串，它们对同一个字符串给出不同的划分：

| 视角                        | 方法         | 结果                |
| --------------------------- | ------------ | ------------------- |
| 字节（bytes）               | `.bytes()`   | 每个原始字节        |
| 标量值（scalar values）     | `.chars()`   | 每个 Unicode 标量值 |
| 字形簇（grapheme clusters） | 第三方 crate | 每个"可见字符"      |

以 "नमस्ते" 为例，三种视角差别明显：

```rust
let s = String::from("नमस्ते");
println!("{}", s.len());              // 18，字节数
println!("{}", s.chars().count());    // 6，标量值个数
```

字节是底层存储的原始单位；标量值对应大多数字符，但某些字符（如带附加符号的组合字符）会显示为多个标量值；字形簇才是人眼看到的"字符"，Rust 标准库不直接提供，需要 `unicode-segmentation` 之类的 crate

### 2.7 对 String 切片

可以对 String 切片，但切片边界**必须落在字符边界上**，否则运行期 panic：

```rust
let s = String::from("hello 世界");

let hello = &s[0..5];   // "hello"
let world = &s[6..12];  // "世界"，每个中文字符 3 字节
// let bad = &s[0..7];  // panic：7 位于"世"的字节中间
```

### 2.8 遍历

遍历字符用 `.chars()`，遍历原始字节用 `.bytes()`：

```rust
for c in s.chars() {
    print!("{c} ");
}

for b in s.bytes() {
    print!("{b} ");
}
```

## Part 3 HashMap

### 3.1 键值对映射

**HashMap**（`HashMap<K, V>`）存储键值对的映射，通过**键**快速查找对应的**值**，基于哈希表实现，查找、插入、删除的平均时间复杂度都是 O(1)，数据无序

### 3.2 创建方式

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();
scores.insert(String::from("Blue"), 10);
scores.insert(String::from("Yellow"), 50);
```

`HashMap::new()` 需要能推断键值类型。另一种方式是通过 `collect()` 从键值对的迭代器构建，例如把两个向量合并：

```rust
let teams = vec![String::from("Blue"), String::from("Yellow")];
let initial_scores = vec![10, 50];
let scores: HashMap<_, _> = teams.iter().zip(initial_scores.iter()).collect();
```

`zip` 把两个迭代器逐对合并为元组迭代器，`collect()` 收集元组构建出 HashMap，`HashMap<_, _>` 让编译器推断类型

### 3.3 访问与遍历

`get` 接收键的**引用**，返回 `Option<&V>`：

```rust
let team = String::from("Blue");
let score = scores.get(&team).copied().unwrap_or(0);  // 缺失时返回 0
```

`Option<&V>` 可以用 `copied()` 解引用得到 `Option<V>`（要求 `V: Copy`），再配合 `unwrap_or` 提供默认值

遍历时**顺序不确定**，与插入顺序无关：

```rust
for (key, value) in &scores {
    println!("{key}: {value}");
}
```

> HashMap 基于哈希表实现，每次运行遍历的顺序都可能不同，不要依赖插入顺序

### 3.4 所有权

`insert` 时，键和值的**所有权会被转移**进 HashMap：

```rust
let field_name = String::from("Blue");
let field_value = 10;
let mut map = HashMap::new();
map.insert(field_name, field_value);
// println!("{field_name}");  // 编译错误：field_name 已被移动
```

如果键或值实现了 `Copy`（如整数、`&str`），插入时是复制而非移动

### 3.5 更新

三种常见更新方式：

```rust
// 1. insert：键已存在时覆盖旧值
scores.insert(String::from("Blue"), 25);

// 2. entry().or_insert()：只在键不存在时插入
scores.entry(String::from("Yellow")).or_insert(50);
scores.entry(String::from("Blue")).or_insert(50);   // Blue 已存在，不改变

// 3. 基于现有值修改
let text = "hello world wonderful world";
let mut map = HashMap::new();
for word in text.split_whitespace() {
    let count = map.entry(word).or_insert(0);
    *count += 1;   // or_insert 返回值的可变引用
}
// map: {"hello": 1, "world": 2, "wonderful": 1}
```

`entry` 返回键对应的条目，`or_insert(0)` 在键不存在时插入默认值 0，并返回该值的**可变引用**，因此可以直接修改实现计数

### 3.6 Hashing Function

HashMap 默认使用 **SipHash** 作为哈希函数，它对哈希碰撞型 DoS 攻击有防护。可以通过 `BuildHasher` 指定其他哈希器（如 Fnv），这里不细讲

## 小结

| 概念                    | 一句话                                       |
| ----------------------- | -------------------------------------------- |
| `Vec<T>`                | 可变长度的数组，相同类型，连续内存，动态扩容 |
| `vec!` 宏               | 通过元素快速创建 Vector                      |
| `push` / `pop`          | 末尾追加 / 弹出                              |
| `insert` / `remove`     | 指定位置插入 / 删除                          |
| `get()`                 | 返回 `Option<&T>`，越界返回 `None`           |
| 迭代器                  | `iter()` + `next()`，for 循环是其语法糖      |
| `String`                | 可变的 UTF-8 字符串，拥有所有权              |
| `&str`                  | 字符串切片，不可变借用                       |
| `push_str` / `push`     | 追加字符串 / 追加字符                        |
| `+`                     | 连接 String，左侧所有权被移动                |
| `format!`               | 不夺取所有权的格式化拼接                     |
| `.bytes()` / `.chars()` | 按字节 / 按 Unicode 标量值遍历               |
| `HashMap<K, V>`         | 键值对映射，平均 O(1) 查找，无序             |
| `collect()`             | 从键值对迭代器构建 HashMap                   |
| `or_insert`             | 键不存在时插入默认值并返回可变引用           |
